# 有界 C++ 调查

仅在用户当前任务需要调查 C/C++ 代码时使用。先确认目标、允许读取的目录和需要证明的命题；
普通实现任务不自动增加计划、任务账本、worktree或子代理。

1. 用现有文本搜索定位少量文件，优先文件名和符号引用。先检查目标文件大小，默认每轮最多
   20个文件、单个256KiB；超限先收窄，明确请求更大范围时另行记录。
2. 判断命题需要哪一层证据：文本命中、语法结构，还是实际编译参数下的类型/重载/模板语义。
   [对照与示例](references/evidence-levels.md)给出各层能证明和不能证明的事项。
3. AST查询只使用项目已经提供并核实身份的ast-grep。记录二进制来源/版本及实际argv，
   先核对该版本公开help；缺失时说明AST路径不可用，不安装包、不运行浮动npx，也不把文本
   搜索结果标成AST验证通过。框架没有将项目提供的CLI声明为Pi已锁依赖。
4. 只对明确的文件执行查询，显式指定C++语言；不把空路径解释为全仓库。禁止rewrite、
   update-all、interactive编辑、follow链接或扩大忽略规则。不得隐式加载项目自定义语言库；
   该版本没有可核实的关闭方式时，停止AST路径。
5. 类型、模板、重载或宏展开结论优先使用项目已有编译数据库、编译器诊断或既有clangd。
   核对compile_commands.json的目录、flags和目标平台；不自动生成全项目索引，不新起常驻服务器。
   缺编译条件时，将语义结论记为未验证。
6. 输出命题、范围、工具身份、确切文件位置和证据层级，并列出未覆盖部分。命中数量和非空
   输出都不等于证明；中断、截断或失败不得自动扩大范围重试。

本Skill只有方法资料，不注册工具或扩展、不改变权限，不提供shell桥或OS沙箱。它不授予
首轮调查子角色额外工具，也不会安装ast-grep扩展、Serena或C++语言服务器。
