## Context

基线为 0c3a189，问题证据见 docs/review-2026-09-13.md。默认测试仍仅使用临时 HOME、阻断网络与假子进程。

## Goals / Non-Goals

修复 R1–R6，增强 capture 和错误定位，建立可测试依赖后端契约。不安装新版本宿主，不扩展到真实 Pi/Codex，不把自动化测试冒充账号或 Agent 行为验收。

## Decisions

- 私人 TOML 使用 no-follow 目录句柄和读取前后身份校验；CLI 选择阶段复用同一入口，不能提前 resolve 链接。现有权限不合规时拒绝，测试数据按私人格式创建。
- profile 所有权记录先于 package/链接写入，记录准备中的目标，最终提交；重试仅接受已记录的前后值。
- runtime 增加关键文件摘要收据；损坏时在同实例锁下暂存重建，替换失败恢复旧目录，固定修复备份支持中断重试。包数据不进入配置备份。
- 锁校验真实 adapter 版本、支持平台和来源声明；未实测平台输出证据状态。来源移入可核对的配方文件。
- OAuth provider_options 暂无已核实字段所有权时明确拒绝；不为通过验收编造映射。
- capture 只读取明确偏好文件与已知原生字段，模型选择仅匹配已声明逻辑模型，不导出动态目录。主题支持锁定版本内建名称和受管主题。
- 公开计划使用稳定非秘密定位编号；具体私有字段映射写入 0600 缓存提案，公开输出不增加 endpoint/model ID。凭据错误提供不含值的定位方式。
- 命令和启动通过 adapter 选择依赖后端；仅注册 DSH 生产后端，以完整假后端命令测试证明扩展契约。

## Risks / Trade-offs

旧 runtime 无摘要收据需一次 sync 重建。旧本地文件可能需用户修正权限。未知主题/模型不捕获为伪配置，明确说明限制。macOS、真实账号、独立 Agent 行为需要后续外部环境及授权，单独维护验收计划。

## Migration Plan

先 validate 检查本地权限和锁；退出实例后 sync、plan、apply。实例 home、账号和会话固定。发生包修复中断重新 sync；配置 pending 先 apply/rollback。
