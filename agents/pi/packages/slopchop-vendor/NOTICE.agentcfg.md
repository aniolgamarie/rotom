# Slopchop in agentcfg

Derived from pi-slopchop 0.10.1 (MIT). The migration manifest records the verified npm archive and original file identities. This fork is 0.10.1-agentcfg.1.

Git queries use a closed supervised argv interface, workspace leases and NUL-delimited paths. Working-file reads use the current file policy. Settings come only from the selected manifest. Editors require an explicit executable binding and literal path/line arguments, write admission and a supervised private PTY when interactive. Ambient EDITOR and shell launch are not used.

Review UI, annotation, submodule views and shortcuts are retained. Native Git/editor/terminal behavior remains unverified until explicit platform acceptance.
