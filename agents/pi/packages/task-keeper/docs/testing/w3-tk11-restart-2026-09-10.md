| 原场景/变体 | 触发与独立观察 | 本批补充的判定 |
|---|---|---|
| TK11 / restart-wait | 真实 Pi 收到 loopback 429；记录等待后 SIGKILL；冷却时刻前重新启动同一 session | 原 Pi 确认退出，离线记录无 intent；请求不得早于持久 notBefore；新进程 owner 身份与 epoch 更新 |
| TK11 / restart-overdue | 同样终止 Pi；接收端继续运行并等待超过原 notBefore，期间不启动替代父进程 | 离线期间只有原请求；recovery/owner 记录不变，无 intent/claim；随后恢复一次原任务 |
| 两者的恢复终态 | 实际 HTTP 请求、持久 SQLite、原生事件和会话消息 | 同 scope/session/incident/history/deadline；一个 settled continuation 带 native ID；原用户任务只出现一次；最终 DONE、claims 释放，排队回调不能重复派发 |
