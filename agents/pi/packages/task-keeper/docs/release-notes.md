## 当前能力

本版实现通用provider/model恢复、完整任务用量和费用、固定inspect/fix、可选第二视角、Pi内一次性定时，以及默认关闭的时段/历史成本选模。首次选模与故障切换分别授权；没有质量失败自动升级cascade。

已验证运行契约为Linux / Node24.1.0 / Pi0.84.4 / 固定补丁pi-subagents0.63.0 / direct openai-completions。普通同路线恢复、受管fresh前台child及声明的受控工具有对应测试。任意扩展、后台/fork child、代理协议、外部工具及所有供应商账号不在统一认证声明中。具体服务需要自己的实网证据，Qwen不是前置条件。

不包含周期任务、退出Pi后唤醒、自动抓价/账单连接器、付费探索、任意多模型图或大型效用实验。原checkout不自动合并，状态/候选不自动清理。

## 如何解读覆盖率

测试通过率、命名验收记录和代码覆盖是三个指标。Scenario状态由验收映射推导，不能自动证明每条语义正确。代码覆盖报告剔除29个非生产路径/修改副本；测试worker已观测原源码的行覆盖84.39%、分支79.30%、函数81.74%。原生Pi子进程尚未完整汇总，因此是部分观测，不称为全产品覆盖率。

原始TAP、完整report.json、code-coverage.json及旧失败属于本地运行产物，不随Git发布。可在包目录执行`npm run test:report -- --release`重新生成；细节见[测试说明](testing/README.md)。无原始工件时，本页仅是可追溯摘要，不是可独立验真的完整证据包。
