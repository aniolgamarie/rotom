# agentcfg Todo adaptation

Source: @juicesharp/rpiv-todo 2.9.0, npm archive. Full extension, UI, state/replay, nine locale dictionaries and MIT license retained.

Configuration and locale selection now come only from agentcfg agent_options.todo; global/project legacy config and automatic optional i18n SDK discovery are removed. Empty prompt guidance is preserved. State remains scoped to native sessions; Todo does not own Task Keeper budgets or scheduling.
