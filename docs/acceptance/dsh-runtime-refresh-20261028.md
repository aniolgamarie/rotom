## Terminal and local approval settings

Native `/settings` can set `fullscreen=false`; `/restart` or a normal quit/relaunch applies it, while `/reload` does not. The native preference takes precedence over a profile YAML default after first import. The inline fixture first initializes a synthetic instance, saves the native preference, and relaunches it. It checks input, a real tool round trip, cancellation and terminal restoration. The bootstrap briefly enters and leaves the alternate screen; the settled chat stays in the normal screen and does not reenable mouse reporting. The fixture does not change the display default of other machines or modify a daily instance.

Perry's argument-matching rules route to `ai`, `human` or `never`, rather than a permanent native command grant. The current local override interface exposes no command allowlist. A caller-controlled build wrapper is not reduced to one operation by its name. The existing one-operation escalation route and `fallbackPolicy=delegate` are retained. Native permissions, reviewer limits, the inline no-tool review path and historical lifecycle/audit limitations are not broadened by this dependency refresh.
