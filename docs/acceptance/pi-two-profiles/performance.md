# Pi 两配置性能证据

2026-10-11：无工具合成 CLI 的纯 Pi 基线及数值预算 revision 1 已生成；Base/Full 性能和体验 gate 未通过。下方准备阶段记录保留为历史，最终实际结果见文末。

本轮先采纯 Pi 基线。固定官方 Pi 1.0.1、Node 24.14.0、本地合成 Provider、空项目和无工具 prompt；断网隔离、私有临时 HOME，无真实账号或付费调用。准备阶段的实际公开 CLI/RPC 已选中合成模型并返回固定响应，但它缺少内层 Node 出生身份与资源轨迹，因此不能作为正式性能样本。

采样排程已在 [验收方法](../../../specs/005-pi-two-profiles/acceptance.md) 固定：3个独立预热，10个 cold 进程，30个连续会话交互。每个预热/cold 进程先 idle 60秒，再1次 prompt，结束后观察30秒；资源间隔100ms。共43个本地合成请求，外部调用与付费为0。失败、超时和缺身份都保留，不能自动重试到通过；100ms tick不算独立统计样本，10个 cold 不报告p95。

采集器正在完成默认假进程/假 `/proc` 验证。实际资源归属必须绑定 outer bwrap 和真正官方 CLI Node 的 PID、出生时刻、父链、namespace、固定可执行文件和 argv；未知身份不记0。Provider 与采集 driver 的资源单列，不计入 Pi。退出后只能报告已验证观测到的进程集合，采样不能证明两次 tick 之间不存在短命后代。

Root 在候选尚无性能结果时，已保存无工具 CLI 比较的工程容忍参数：延迟、RSS、CPU 和FD使用绝对与相对上限中较严者，额外 idle 后代及结束30秒仍存活的观测后代上限为0。参数见私人 `pure-pi-performance-tolerances-review01/tolerances.json` 和决定说明；它们不是基线结果或通过事实。正式纯 Pi 基线产生后，由 `scripts/pi-freeze-budgets.py` 生成绑定平台/方法/工具/输入的数值工件，落盘后才采候选。

真实 Provider 延迟、审批六项质量指标、C++/Shell/Neovim工作负载性能、取消延迟、实际 TUI中文输入/滚动和人工体验均未测；不以此次无工具基线代替。Full idle/active和smart启用/关闭仍有独立证据要求，AUTO继续关闭。
