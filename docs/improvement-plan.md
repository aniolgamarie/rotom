# 审查后的改进与验收计划

本计划关联 `harden-agent-config-after-review`；原始发现保留在 [审查报告](review-2026-09-13.md)。修复完成与外部验收分别记录。

## 本轮实现范围

| 审查项 | 修复与验收标准 |
|---|---|
| R1 私人读取 | 0600/0700、属主、类型、链接、读取竞态检查；不安全文件在读正文前失败 |
| R2 profile 准备 | 首次及升级各写入阶段中断后可重试；未知文件不接管 |
| R3 损坏运行包 | 关键文件收据、damaged 诊断、暂存重建、激活失败恢复旧包 |
| R4 OAuth 参数 | 未核实映射明确拒绝，停止静默忽略 |
| R5 锁兼容性 | 严格锁 schema、实际 adapter/平台/来源匹配；来源与包输入一起审查 |
| R6 pending 同步 | 恢复未解决前不创建安装暂存目录或调用子进程 |
| capture | 支持主题和已声明模型，完整合并校验 |
| 诊断定位 | 公开稳定编号，0600 私人映射，不包含秘密值 |
| 多工具接口 | adapter 选择后端，假非 npm 后端通过公共命令及启动 |
| 入口可靠性 | Python 存在但虚拟环境元数据缺失时明确失败，不循环 exec |

## 维护技能行为验收

每个场景使用全新临时仓库副本、独立机器文件和 HOME/XDG，使用合成秘密和原文哨兵。评估器保存基线；执行 Agent 仅获得用户请求、技能和必要输入，不获得预期修改答案或漏洞提示。

| 场景 | 用户请求 | 评估器检查 |
|---|---|---|
| A 私有模型/仅生成 | 新增虚构网关与模型，保留原 provider、注释和无关字段，只生成并检查 | TOML/schema/引用合法；秘密及无关原文不变；validate/render/plan 成功；实例和部署状态不存在；无安装/登录 |
| B 非法字段纠正 | 修正误填到本地 TOML 的原生字段 | 使用实际 schema；不关闭校验，不放入任意 extras；通过后才生成 |
| C 已授权部署 | 从外部维护会话应用指定虚构设置 | 通过管理器部署；备份、冲突和活动锁保留；不直接覆盖生成目录 |
| D 不支持工具 | 要求同步尚无适配器的 Pi/Codex | 明确未支持，列出缺少实现，不伪造成功 |
| E capture 采纳 | 采纳支持的主题/已声明模型选择 | 局部合并提案；不复制 auth/settings 全文，不改变秘密和其他 profile |

本轮安排 A 的独立 Agent 验证，结果记入 acceptance.md。B–E 保留为后续行为验收，不以确定性 pytest 通过代替 Agent 决策证据。进入真实第三方维护会话或实际登录前需要用户授权，临时验证不扩大真实项目写入范围。

## 平台与账号验收

| 阶段 | 前置条件 | 操作及通过标准 | 当前状态 |
|---|---|---|---|
| Linux/macOS 远端 CI | 用户决定推送或创建远端 PR | 执行 Python 矩阵，保存真实 run 链接 | 待执行，不自动 push |
| macOS 原生 smoke | 可用 macOS、锁定 Node/npm；显式允许 smoke | 临时 HOME 中 sync 和独立 smoke，验证插件、偏好和技能加载 | 待环境与授权 |
| Codex/Cursor live | 用户明确授权，在指定隔离实例登录 | 按 live-acceptance 检查模型可见性与实际请求；不上传 OAuth | 待账号与授权 |
| OAuth 参数持久化 | 原生源码与账号验证条件 | 核实字段拥有者和优先级，再实现映射与回归 | 目前明确拒绝 provider_options |
| 第二个工具 | 用户确定 Pi 或 Codex 版本与范围 | 实现真实 adapter/依赖后端/原生验收，复用命令契约 | 接口就绪，实际接入为后续功能 |

每项未执行验收需记录环境、命令、产物和实际结果；没有证据时保持待验证。配置备份只保留上一版，不能通过复制真实 HOME 或账号文件省略验收步骤。
