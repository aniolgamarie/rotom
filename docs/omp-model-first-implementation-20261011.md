# OMP 模型优先审批实施与离线验收

日期：2026-10-11。状态：实现完成，离线验收通过。
后续隔离宿主八例通过，真实主审三例中两例通过、一例回复协议失败；见[宿主与真实主审记录](omp-model-first-host-20261011.md)。本机部署尚未验证。
开发分支：`fix/omp-approval-observability`。本记录不表示已经合入 main 或更新运行中的 OMP。

## 行为变化

本轮按[已确认方案](omp-model-first-solution.md)修改仓库自有权限插件。
smart 模式中的普通有效请求先构造脱敏审查包，再交主审模型。
解析器不支持的语法、循环、动态参数和普通 `Authorization:` 文字不再直接要求人工审批。
解析结果只提供辅助事实；未知语法不会被当作风险决定。
明确命中的原生或配置 deny/prompt，以及用户主动选择的人工模式，继续按对应规则处理。
空请求、失效调用和无法绑定的执行路线分别记录为输入或集成状态问题。

命令、参数、选取的真实用户指令和执行上下文均在进入模型前脱敏。
主审与远程备用只能接收同一个已校验、冻结的审查包；传输接口拒绝原对象、伪造对象及未经校验的副本。
遮蔽假秘密时保留选项用途、外发目的地及其余命令全文，不截断当前操作来取得批准。
审查包大小上限为 24 KiB，用户历史另有预算和省略标记；必需内容放不下时报告容量故障。
原命令及参数仅在本地保留用于执行和批准绑定，实际执行不使用脱敏后的命令。

主审优先使用主动配置的 reviewer，未配置才选择会话模型；执行模型与主审分别选择。
远程备用只处理服务或协议失败，有效 ask/deny 不会继续询问其它模型寻找 allow。
tiny 本地层仍为 unavailable，未接入私有宿主接口，也未自动安装模型。

批准绑定当前调用、命令及参数、用户授权、会话、工作目录、配置代数和原生设置。
取消、撤销指令、待处理用户消息或工作目录变化使旧批准失效，之后不能继续备用审查或执行。
已经发出的 HTTP 请求无法撤回；返回后仍须重核绑定，失效结果不再触发人工询问或执行。
具体硬拒绝规则的目标尚不能确认时，模型批准和模型服务故障后的人工批准均不能解除该限制。

审计增加辅助分析状态、规则编号、脱敏及历史省略信息，并保留主审/备用失败分类和最终来源。
审计不保存命令正文、用户正文、原始模型响应、请求 body 或秘密值。

## 验收结果

全部检查使用假模型、假执行与合成配置；未启动真实 OMP、未请求真实模型，未加载本机账号或密钥。

| 检查 | 结果 | 可以证明的范围 |
| --- | --- | --- |
| 插件及相关 Bun 测试 | 685 passed，0 failed，118,590 次断言，25 个文件 | 输入脱敏、主审/备用协议、规则边界、取消和批准绑定回归 |
| 冻结命令集三路径测试 | 34,419/34,419 passed，0 failed | `permission_bash`、native Bash、native zsh 的模型路由、完整输入及原参数绑定 |
| Python 受影响模块 | 105 passed，7 skipped | 资源、依赖锁、合成部署及秘密边界；跳过项目不计为通过 |
| 官方 OMP 18.8.6 SDK 类型检查 | 退出码 0，无诊断 | 使用实际官方公开类型的兼容性；不代表运行时宿主验收 |
| 插件树和依赖锁严格回读 | 201 项资源通过 | 插件摘要与锁一致，官方上游和运行资产保持原样 |
| 稳定变更独立复核 | 未发现新增实质问题 | 当前代码的脱敏接线、失效检查、拒绝规则和测试预期来源 |

冻结集仍为 11,473 条原记录，其中一条为空命令，按输入无效拒绝。
每条路径其余 11,472 条全部到达模型：有效命令覆盖率从基线的 87.85% 提高到 100%。
三路径合计 34,416 次假模型调用。此批次统一注入 ask，假 UI 选择 Deny，
所以同样产生 34,416 次人工分支调用、实际语料命令执行数为 0。
这些人工分支发生在模型明确返回 ask 之后，不是语法门控；不能把这个数字理解为真实模型的询问率。
allow/ask/deny、远程备用及原生委派另有针对性合成测试，不能用假模型结果证明真实风险判断质量。

测试预期来自冻结记录、固定语法差量和独立标注的假秘密跨度，未使用新解析器或脱敏器自动生成期望。
实际序列化的主审和备用请求也检查嵌套字段中的秘密 canary。
引号拼接的 Bearer 假秘密曾暴露遗漏，已修复并加入独立预期与传输出口回归。

Python 首次沙箱运行有 22 项因运行 UID 与临时祖先目录属主不一致而失败。
在实际 UID、独立临时目录中重新运行后为 105 passed、7 skipped；没有降低文件所有权保护。
测试完成后再次核对核心源码摘要，确认通过证据对应最终源码。

## 尚未验收及能力边界

真实宿主入口及三条真实主审样本的后续结果见上方记录；完整模型质量、快速复制 clone 效果及本机部署仍待独立验收。
本轮离线通过不能证明所有实际命令都无需人工，也不宣称解决远程模型服务故障。

本轮脱敏覆盖模型内容和插件自己的人工提示、状态及审计。
宿主原始 tool call、会话和工具结果不由此插件改写；应优先使用凭据引用，避免把真实秘密写进命令。
检测器能处理已知凭据位置和格式，不能保证识别任意秘密文本，不主动读取密钥文件或环境来扩展识别。

规则辅助分析能识别常见包装器和明确的字面操作，不能证明任意程序或 Shell 脚本的所有副作用。
模型批准也不提供操作系统隔离。
async、service、PTY 和预先存在的 shell snapshot cache 等未覆盖路线继续明确报告限制。
