# Synthetic OMP command corpus

The public corpus is synthetic, has stable case identities, and is independent of private session history. It must not be regenerated from a user account as part of ordinary tests. The frozen 11,473 records include one invalid empty command; model-first routing tests inject deterministic review and do not prove real-model risk judgments. This path remains for the locked fixture README. See [testing](../testing.md), [approval design](../design/approvals.md), and [approval diagnostics](../omp-approval-diagnostics.md).
