# Contract: 有限调查协作与状态栏信息

适用：FR-019–026。此契约同时规定尚未满足的交付条件与允许的降级，
不能因候选暂停而将要求删除。候选身份及理由见 [research](../research.md)。

## 1. Pro 首轮准入

Pro 的基础配置可与 Base 一起准备，但协作当前 `not_ready`：不加载委派器，
显式请求启用不满足条件的组合返回配置/能力错误，不能静默改为普通调查后标 Pro 完成。

每个精确候选必须同时满足：

1. 每个主会话最多两个实际运行的调查子任务，各主会话独立计数；
   所属主会话的第三个请求在启动前排队或拒绝，不能只依赖模型自觉或借用其他会话名额。
   两个主会话可各运行两个调查，合计四个；不设置全配方合计两个的限制。
   取消请求或退出未知不能提前释放所属主会话的并发名额。
2. 子任务不得写项目或执行任意 shell/命令桥；选中工具及 MCP/Codemode/恢复会话等间接通路
   都在已核对只读闭包内。必要本地会话/结果输出仅限其声明归属，不等于允许项目写入。
3. 子任务不能继续委派；嵌套入口、批量和恢复不能绕过深度与数量限制。
4. 首轮无后台或写入 worker；父会话退出、失败与取消路径均能提供可解释结果和进程状态。
5. 子任务使用明确的角色、资源、认证归属与会话位置，不隐式安装或加载未准入项目资源。
6. 模型与结果对应当前请求；实际模型不可确认时标未知，不拿请求字段冒充回执。

只读工具限制针对公开执行入口，不宣称 OS 沙箱。若必须借任意执行工具才能完成调查，
该首轮受限角色不提供此能力；需要扩大范围时单独修改设计与验收，不能自动放宽。

`@mjakl/pi-subagent@3.1.0` 当前不满足每主会话强制并发 2 的公开配置条件，不能原样准入。
深度 1 与循环保护只是待验证路径的一部分。其他包须独立核对，不能通过
新增自有调度器、改插件源码、修改宿主或复制旧 AgentManager 绕过准入。

## 2. 任务观察与取消

主会话负责拆解、根因判断、写入与最终验收；子代理仅返回任务包范围内的证据。
没有共享任务数据库或恢复协调服务；结果使用候选自身公开能力和必要文件化交接。

| 观察维度 | 必须区分 |
| --- | --- |
| 主会话归属 | 每个调查关联唯一主运行，计数、结果、取消及名额释放不能串用 |
| 执行 | queued、running、succeeded、failed、unknown |
| 取消 | 尚未请求、已请求、已收到回执 |
| 进程 | 确认活动、确认退出、未知；父退出不代表后代退出 |
| 结果 | 本次身份匹配、完整、截断、空、缺失；非空不等于通过 |
| 副作用 | 无副作用的已核实证据、已观察变化、未知 |
| 模型 | 请求、宿主选择、服务可确认实际值，后者允许未知 |

取消只是一条控制请求，不能直接将任务标为资源已回收。结果完整也不能说明项目审查已通过。
无回执或副作用未知时不自动重试；存在活动/未知后代继续阻止受影响维护。
不承诺 Pi 重启后自动恢复任务或长期进程；交接记录保留目标、产物、检查、失败和下一步，
不复制完整会话或凭据。

## 3. 相同任务的候选验收

候选先做同一套测试：单调查、双调查、所属主会话第三个请求、两个主会话各运行两个调查、
跨会话结果归属与名额不串用、取消/未知退出不提前释放名额、递归请求、越界工具、继承项目资源、
模型不可确认、空/截断结果、工具失败、取消、父退出及未知后代。

默认隔离测试只能证明管理器生成的约束和状态处理；真实候选是否遵守须分别进行原生组合验收，
涉及模型或账号再获得对应授权。任何必需条件缺失，保持 held/not_ready，不扩大支持声明。

## 4. 十类状态栏信息的正式口径

以下是旧栏需求的承接，不是要求复用旧扩展或保留错误算法。

| 信息类 | 数据含义与首选公开来源 | 缺失/变化处理 | 显示优先级 |
| --- | --- | --- | --- |
| 提供方/模型/思考强度 | 当前宿主可公开确认的选择；请求与上游确认分列 | 切换后更新；不把桥接选择当服务端证据 | 最高，60 列仍可辨认 |
| 项目与 Git 分支 | cwd 的项目简称、公开 Git 查询 | 不显示私人绝对路径；分支改变刷新 | 中，长名可截短 |
| 输入/输出用量 | 当前会话分支的 assistant usage 累计 | 继续/切分支不重复累计；注明范围 | 中，可收拢 |
| 缓存 | 读取量与读取占比；分母为 input+cacheRead+cacheWrite | provider 未上报则 unknown；写入量可作新增显示，不冒充旧必需项 | 宽屏或二级 |
| 费用 | provider 上报或明确估算的累计费用，注明范围/币种/来源 | 订阅桥无账单值时 unknown，不把缓存率推成真实费用 | 宽屏或二级 |
| 上下文 | 当前公开 context tokens/window、比例及风险 | 模型切换/压缩后重算；未知 window 不回退猜 200000 | 最高 |
| 会话时长 | 公开可确认会话起点到当前时间 | 继续或重载须说明起点，不拿进程时长代替 | 二级 |
| 主会话活动 | 适用公开 agent 活动事件与状态 | 不单凭 turn_end 宣称 idle；与后台存活/任务成功分开 | 最高 |
| 速度 | 若可提供则说明分子、时段与算法 | 旧上下文增量/秒不叫输出 token/s；压缩等造成不可比则不显示伪精度 | 低 |
| 权限摘要 | 仅来自新组合可确认的公开权限来源 | 不继承旧 session-yolo 私有 Symbol；无来源则 unknown/不显示保护承诺 | 按可用性 |

总 token 不是 context token；累计用量不得把工具文本再算一次，子任务也不得同时合并为父用量
又单独相加。费率不明或 provider 不上报的数据不可按零填充。
旧栏没有 dirty、子代理或长命令进度，不把新增字段当作旧信息对齐的必达条件。

## 5. 布局、生命周期与公开接口

- 用 60、90、130 列作为测试宽度，不要求重现旧 70/120 断点实现。
- 最窄时优先模型/提供方/effort、主会话活动、上下文风险；统计可收拢，须能辨认或展开查看。
- 中文、宽字符、长名称、resize、SSH/tmux、输入粘贴、取消、重载和退出均须测试，
  不覆盖编辑器私有状态、不伪造终端宽度或后台存活。
- 单一界面所有者；customItems 或公开 setStatus 只提供显示接口，不能自行创造缺失数据。
- 不为显示引入隐式模型调用、无限自动 follow-up 或不必要高频 Git 轮询。
- 只初始化可由用户选择的 UI 偏好，持续受管选项逐项明确；隐藏显示不能作为关闭 hooks 的证明。

Powerline 0.20.2 当前暂停准入：没有已核实可关闭所有不允许路径的公开配置，
不进入默认/可选配方或新锁。关闭 fastRender、段显示、queue compact 模式仍不能证明合规。
将来若上游以公开接口解决，须重核精确发布包、所有注册 hooks、统计口径和交互组合。

允许阶段性交付原生 UI，并公开列出缺口；这只能完成 Base 的回退体验。
十类对照须 100% 有处置，能公开确认的信息须覆盖。未覆盖差异只有获得用户明确接受后才能
标为信息对齐完成；此计划不替用户接受缺口。Pro 和完整 feature 的验收状态与 Base 分开。
